# Smart Task Scheduler

A simple desktop-based task management application built using **Java Swing**.

The Smart Task Scheduler allows users to create tasks, assign priorities and deadlines, mark tasks as completed, delete tasks, and save task information locally.

## Features

- Add new tasks
- Set task priority
  - High
  - Medium
  - Low
- Add task deadlines
- View tasks in a table
- Mark tasks as completed
- Delete tasks
- Automatically save tasks
- Load previously saved tasks when the application starts
- Simple and user-friendly graphical interface

## Technologies Used

- Java AWT
- File Handling
